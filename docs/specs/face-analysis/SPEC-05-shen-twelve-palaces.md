### 結構特性（後台與程式設計必須支援）

1. **一宮多部位**，分主／輔；夫妻宮以奸門為主、眉眼鼻印堂十字帶複合看。
2. **財帛宮分年齡段**（三倉）：報告需依會員年齡選擇對應部位；筆記給定人倉 31-50，天倉／地倉切分歲數請老師最後核可。
3. 宮名以沈師版為準：**父母宮、夫妻宮、子女宮、奴僕宮**（不用相貌宮、妻妾宮、男女宮）。
4. 多宮共用同一部位（印堂至少出現在命宮、官祿、遷移、福德、夫妻），部位觀察一次、多宮引用。

## 二、細部位清單（Vision v2 需要新增的觀察目標）

沈師體系實際使用的部位，遠細於現行八大區塊（forehead/eyebrows/eyes/nose/cheeks/mouth/jaw/ears）：

印堂、日月角、山林驛馬（額角）、天倉、山根、年壽、鼻准、鼻翼、奸門（眼尾）、
眼瞼（上）、淚堂／眼袋、人中、仙庫、法令、嘴角、地閣、懸臂、腮骨、顴骨、命門（耳前）、眉頭／眉心／眉尾。

Vision v2 原則：仍只回傳**可見幾何形態**（寬窄、高低、豐隆／凹陷、對稱、清晰度＋信心度），
維持 strict schema 禁止身分／年齡／健康／人格欄位；細部位判讀不到時回 not_assessable。

## 四、程式改動範圍（實作時逐項核）

- `lib/face-analysis/rules.ts`：`FACE_PALACE_NAMES` 換沈師宮名與順序；對應表改「一宮多部位＋主輔＋財帛宮年齡段」；status 判定改以形態特徵（contour／relativeWidth／relativeHeight／symmetry）為主，拍攝條件（illumination）降為 caution 不影響宮位狀態。
- `lib/face-analysis/vision.ts` + `gemini-image.ts`：regions 擴充細部位（schemaVersion 升 2.0）——**下一批**。
- `lib/face-analysis/report.ts`：outputContract 宮名序列同步；rules JSON 附各宮沈師部位說明。
- `report-schema.ts`：宮名經 `FACE_PALACE_NAMES` 自動傳導，無需另改。
- 後台 `face_rule_profiles`（新 migration）＋ `/admin/face-rules`：老師可勾選／調整對應與判讀依據，具名發布，版本記入 `face_analysis_runs`。
- 知識卡：補「宮位×部位×特徵→論斷」結構化條件欄位；現有 28 張草稿對照 22 頁檔與筆記整理稿重核。

## 五、安全分級（審核時逐條，不整章過）

- 允許進報告：形態→趨勢式文化參考（例：鼻准豐隆＝賺錢能力好的傳統說法）。
- `critical` 禁止進報告：疾病／癌症／壽命／生育／性功能／心理診斷／婚姻定論／外遇推斷／由臉判定他人可信度。
- 教材同一段落常混雜兩類（283 頁整理稿已逐條標 `⚠️CRITICAL`，共 964 條），知識卡逐條拆分分級。

## 六、待老師確認清單

1. 十二宮對應表（本檔第一節）整表核可，特別是奴僕宮（筆記 p.90-91 內容較少）。
2. 財帛宮三倉切分歲數（筆記僅明示人倉 31-50）。
3. 夫妻宮十字帶各部位的主輔權重。
4. 細部位清單有無遺漏／需優先者。
5. 氣色與痣紋是否要做、可靠性門檻。
