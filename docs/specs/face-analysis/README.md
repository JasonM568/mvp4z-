## 已確認決策

- 本功能直接整合至 `xunfeng-official-v2`，不建立獨立 App、會員、點數或金流。
- 技術棧沿用 Next.js 15 App Router、React 19、TypeScript、Supabase、Vercel 與既有 AI provider。
- 新正式路由為 `/member-ai/face`，並由既有 `SiteHeader` 導覽進入。
- 第一階段採「免費本機照片品質檢測＋完整面相報告 20 點／次」。不建立原型中的 NT$99／399／1,299 單次商品。
- 點數只由後端判定與扣除，成功產出合格報告後才扣點；同一請求不得重複扣點。
- 照片不得公開存放於 `public/`。原始照片預設於報告完成後 24 小時內刪除；會員可保存報告文字，但不永久保存臉部照片。
- 系統必須先確認「單一、清楚、正面人臉」，不得以檔案內容 seed 或隨機值冒充影像判讀。
- 面相內容定位為民俗文化與個人趨勢參考，不輸出醫療診斷、投資保證、犯罪傾向、種族、宗教、性傾向等敏感推論。

## 明確不沿用的原型行為

- 不使用 Base64 字串抽樣產生清晰度、光線、可信度或運程分數。
- 不允許上傳非人臉圖片後仍生成報告。
- 不以 `localStorage` 儲存正式點數或任務完成狀態。
- 不提供按一下即可領點的未驗證任務。
- 不在消費者頁面顯示「商業服務原型」「付費層級建議」「上線注意」等內部資訊。
- 不讓前端決定點數餘額、扣點成功、報告解鎖或付款狀態。

## 全域完成定義

四份 SPEC 依序完成、migration 可重複安全部署、RLS 測試通過、`npm run build` 通過、核心 API 測試通過，且以真人照片、多人照片、非人臉圖片、模糊照片、重複請求及點數競態完成驗收，才可視為可上線。
